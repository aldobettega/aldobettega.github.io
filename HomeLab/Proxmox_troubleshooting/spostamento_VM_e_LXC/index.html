Come cambiare ID alle macchine

Per cambiare in sicurezza id a VM e Container occorre clonare questi servizi con un ID nuovo. Per farlo basa eseguire questi passaggi.

VM

  1. spegnere la VM che vogliamo clonare
  2. verificare che la VM che stiamo clonando abbia su Hardware > CD/DVD Drive su "Do not use any media"
  3. clonare dalla shell del nodo proxmox con qm clone ID_VM_ATTUALE ID_VM_NUOVO --name NOME --full 1
  4. controllare che si avvi correttamente la macchina clonata
  5. eliminare quella vecchia se va tutto bene

LXC

  1. spegnere il container che vogliamo clonare
  2. clonare con pct clone ID_LXC_ATTUALE ID_LXC_NUOVO --name NOME --full 1
  3. controllare che si avvi correttamente il container clonato
  4. eliminare quello vecchio se va tutto bene
